# 🌦️ Weather App

A simple and responsive Weather App built using **HTML, CSS, and JavaScript** that fetches real-time weather information using a weather API. Users can search for any city and instantly view the current weather conditions.

## 🚀 Features

* 🔍 Search weather by city name
* 🌡️ Displays current temperature
* 💧 Shows humidity
* 🌬️ Displays wind speed
* ☁️ Weather condition with icon
* 📱 Responsive design for desktop and mobile
* ⚡ Fast and easy to use

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)
* Weather API
